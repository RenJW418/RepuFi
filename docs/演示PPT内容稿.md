## 第 1 页 · 封面 + 理念

**主标题：RepuFi — 让信誉成为可交易的资产**

**副标题：一个以声誉为核心的质押与对赌市场**

**核心理念（3 句）：**
- 让个人 / 项目方 / 公众人物用**真金白银为自己的承诺背书**
- 由 **AI Agent 做市与裁决**的市场，为"你会不会做到"实时定价
- 做到了，就铸造一份**伪造不了的链上信誉**

**一句话点睛：** 投钱对赌 → 完成目标 → 铸造信誉。**对赌是引擎，信誉是产品。**

> 视觉：中央大标题 + 一条"信誉曲线"上扬的示意图。

## 第 2 页 · 核心亮点：多层裁决机制（保证结果足够可靠）

**标题：怎么判断"到底做到没有"？——四层束缚，逐层校验**

**流程（建议做成从上到下的流水线图）：**
1. **⏰ 倒计时结束** → 事件到期，进入裁决
2. **🤖 主 Agent 提交提案** → 先给出一个初判：守约 / 违约
3. **🔮 预言机给出最终结果**（参考 Polymarket 的 UMA 乐观预言机：提案 + 质押保证金 + 争议窗口）
4. **⚖️ 多 Agent 陪审团交叉复核** → 3 个独立 Agent 各自核验证据，判断这个结果是否可靠
5. **🗳️ 不一致则升级人工复核** → 代币持有者投票，并做**利益隔离**（发起人、参与者、关联方不能投票）

**一句话点睛：** 单点容易错，**多层叠加 + 相互制衡**，才敢把结果写上链。

> 视觉：纵向流水线 4–5 个节点，每个节点一个图标；冲突分支用红色高亮"升级人工复核"。

## 第 3 页 · 覆盖范围：同一套机制，三层场景递进（L1 / L2 / L3）

**标题：从个人自律到公众问责，一套机制全覆盖**

| 层级 | 场景 | 演示案例 |
|------|------|----------|
| **L1 日常生活** | 个人自律 | 姚帅能否连续 30 天早睡早起 |
| **L2 项目交付** | 项目方里程碑 | RepuFi 能否在 Q3 完成主网上线 |

**关键点：** 三层只是**换了"谓词"和"裁决来源"**，底层的质押—对赌—裁决—信誉机制完全一致 —— 可无限扩展到任何"可量化、可验证"的承诺。

## 第 4 页 · 分配机制 + 可信度保障

**标题：钱怎么流动，可信度怎么保证**

**① 发布者（事件主体）——双向正向激励**
- 发布前需**质押一笔保证金**
- **守约** → 保证金全额拿回 + 获得**声望积分奖励**
- **违约** → 保证金被罚没 + 留下永久信誉污点
- 无论成败都获得了"声望背书"的推动力，激励他认真做事（发布者不拿对赌分润，只拿信誉积分）

**② 参与者（对赌方）——参考 Polymarket**
- 押"守约（Commit）"或"违约（Skeptic）"
- 按两侧资金比例定价、按结果分润

**③ 可信度保障——防止乱发事件、保护参与者**
- **社交媒体认证（X / 推特）+ KYC 认证**（均为可选）
- 认证越全，事件可信度越高，防钓鱼、防身份冒用

**④ 一键社交曝光**
- 事件创建后，连接 **xAPI**，一键推送到绑定的所有社交媒体，短时间内引爆热度

> 视觉：左侧"资金流向"图（质押→守约退回/违约罚没），右侧"可信度徽章"（𝕏 ✓ / KYC ✓）。

## 第 5 页 · 技术底座 + 畅想

**标题：信誉资产化——把抽象的"声望"变成可交易的资产**

**技术强调：**
- 全流程的 **AI Agent 模型均来自 xAPI**（统一模型层 + 社交媒体 API）
- 链上托管、中立结算、自验证谓词、信誉可组合

**畅想（收尾升华）：**
- 信誉 / 声望本是**抽象、难衡量**的概念
- RepuFi 用"**市场定价 + 链上铸造**"把它变成：
  - **可定价**——市场给你的违约概率，就是难度系数
  - **可交易**——围绕承诺的对赌市场
  - **可组合**——不可转移的信誉 SBT，可被其他协议引用
- **飞轮：** 信誉 → 定价 → 守约 → 更高信誉

**结束语：** 让每一个被守住的承诺，都成为一块可验证、可增值的**信誉资产**。

> 视觉：中央一个"信誉飞轮"循环图 + 底部一行 slogan。
